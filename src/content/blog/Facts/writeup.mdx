Al buscar información sobre este binario en GTFOBins, se observa que `facter` permite el uso del parámetro `--custom-dir`. Este parámetro hace que el programa cargue “custom facts”, es decir, scripts Ruby desde un directorio que le indiquemos. Lo importante aquí es que `facter` ejecuta el primer archivo `.rb` que encuentra en ese directorio.

La idea de la explotación es bastante directa: si podemos controlar ese directorio, podemos introducir nuestro propio script malicioso en Ruby. Como `facter` se va a ejecutar con `sudo`, ese script también se ejecutará con privilegios de root.

El proceso sería así:
1. Crear un directorio controlado por nosotros (por ejemplo en `/tmp`).
2. Dentro de ese directorio, crear un archivo Ruby con código que abra una shell.
3. Ejecutar `facter` como root usando `sudo` y apuntando al directorio que hemos creado con `--custom-dir`.

Un ejemplo sencillo de script Ruby sería:

```ruby
exec("/bin/bash")
```

Al ejecutar:

```bash
sudo facter --custom-dir /tmp
```

`facter` cargará el script desde ese directorio y lo ejecutará como root, lo que nos dará una shell con privilegios elevados.
